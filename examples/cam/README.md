# CAM examples

## rotary-shop-tools.json

A 129-tool **placeholder library** in SolidCraft's own tool format (the `tools` list of a
design's `manufacture.tools`, with ids left out so they are given on adding). Each entry can be
passed to `cam.tool.add`. It is the owner's own list, first kept in another program; nothing in
it came from that program's library. It is meant to be edited: every machine and every user is
different, so the user sets each tool's numbers from their own machine and its documentation.

**No tool carries speeds or feeds.** Every entry is size and shape only. The owner built it for
their own heavily modified machine, so their settings would not suit anyone else's, even on the
same model. The planner or `cam.tool.kit` fills speeds and feeds in from the machine and the
material, or the user enters their own.

Where it comes from (no manufacturer catalogue data):

- **10 shop tools** (T1 50 mm facing tool, T4 6.35 mm and T5 3.175 mm end mills, T6/T7 ball end
  mills, T22 and T25–T28 4–8 mm carbide drills): the sizes of the owner's own cutters.
- **119 generic tools**: standard sizes generated by a script, not taken from any catalogue:
  flat, ball and drill sizes from 2 to 12 mm and 3/32 to 15/32 in, 90 and 60 degree chamfer mills,
  30/60/90 degree V-bits (entered as chamfer tools) and face mills.

Lengths are there to satisfy the program and its holder and shank checks; tool length offsets
are set at the machine. `holder_diameter` is left at 0 for each user to enter for their own
holders.

Generic tools whose numbers clashed with the shop tools were left out, as were T-slot and
dovetail cutters (no tool kind for them yet).
